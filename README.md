# 🌆 Urban UI Library (v2.5)

Uma biblioteca de interface gráfica moderna, fluida e altamente customizável para Roblox, inspirada na *Wind UI*. Desenvolvida para ser simples de integrar e visualmente elegante.

> 👤 **Criado por:** `vortex_py`

---

## ✨ Recursos Principais

* **Barra de Pesquisa de Abas:** Filtre suas abas em tempo real.
* **Perfil do Jogador Integrado:** Exibe automaticamente a foto de avatar e o nome do usuário no rodapé da UI.
* **Diálogos Modais estilo Pop-up:** Janela de confirmação para ações importantes.
* **Ícone Flutuante Redondo Customizável:** Redimensione o ícone interno do botão minimizar (`FloatIconSize`).
* **Notificações Toast Modernas:** Sistema de avisos suaves e temporizados.
* **Suporte a Redimensionamento e Arraste:** Mova a UI livremente ou ajuste seu tamanho pela alça `◢` no canto inferior.

---
